# Опора, объём и оформление островов — дополнение PR #13

Пальмы и небольшие предметы больше не получают растянутую высоту холмов. Их составные части сохраняют пропорции и ставятся на реальный рельеф. Технические исправления и оформление выполнены в том же тематическом PR отдельными коммитами:

| Коммит | Изменение | Тесты / build |
|---|---|---|
| `f9e2b6a` | Исправление отражений и шва дальнего моря high | 56 / OK |
| `e85af19` | Привязка нативных пальм/пропсов к земле | 57 / OK |
| `48e2bf0` | Нижняя оболочка и стенки открытых краёв островов | 58 / OK |
| `b351b60` | Фактура песка/травы/камня, древесина, палитра | 58 / OK |
| `423b810` | Детерминированные группы объектов через instancing | 59 / OK |
| `88fefbb` | Размеры стола, забора, припасов, сухих деревьев и мелких растений | 60 / OK |

Верхний рельеф остаётся непрозрачным двусторонним, открытая бухта не перекрывается диском. Под ним добавлены нижняя оболочка и стенки. Форма береговой коллизии и океанская маска рассчитываются по прежнему физическому рельефу, без нового основания и декора. Все три задания, островные идентификаторы, швартовка и отдельный босс сохранены.

Оформление использует имеющиеся V3-детали, `palm_tree`, `rock_cluster` и шесть PNG 512×512 из репозитория (496 241 байт файлов). Новых GLB островов нет. Карты могут впервые запрашиваться для грунта; загрузочный кэш делит исходные изображения. Трава, песок и скалы выбираются по авторской раскраске, деталь проецируется в метрах, добавлены умеренные normal maps.

В фактической сцене после исправления размеров добавлены 170 пальм, 146 камней/групп камней и шесть хижин. Часть пальм использует более подробную модель из старого кита, часть — исходные формы острова. На вулкане зелёные рощи не создаются. Точки детерминированы, учитывают сухую землю, уклон, существующие постройки и запас вокруг центра. Коридор от причала имеет ширину 12 м. Лимит декора — 24 000 треугольников на остров, для пальм 17 000.

## Проверки и материалы

- `npm test`: **60/60**, `npm run build`: успешно на ветке островов.
- `/scripts/environment-smoke.html`: **51/51** в реальном WebGL. Осмотрены все шесть моделей, низкий береговой ракурс, камера внутри грунта и вулкан сбоку; сравнение low/medium/high на основном острове. Смена качества также проверяет компиляцию шейдеров.
- Узкие места физики дополнительно проверены в совместной локальной сборке: швартовка у трёх островов в обоих направлениях, берег, пушки, бой и вход/выход в «три в ряд». Проверки не выполнялись на порту капитанского сохранения 5174; использован отдельный порт 5176.
- Снимки и JSON: `docs/environment/polish/`. Исходный вид большой пустой площади: `docs/environment/island.jpg`. Снимки — реальный браузер, не рендеры из архива.
- `node scripts/island-metrics.mjs`: воспроизводимый геометрический отчёт. Один прогон Node для шести моделей с одинаковым seed и без внешних игровых причалов: **165 822 треугольника**, 66 мешей, **7 798 280 байт** геометрии и **29 120 байт** матриц инстансов. До этих правок: 47 508 треугольников, 22 меша, 5 339 592 байта геометрии. Это число всех островов, а не счётчик одного видимого кадра. В сцене другие seed у декоративных островов, поэтому точные количества треугольников могут отличаться.

## Проверка вручную и ограничения

Открыть `/scripts/environment-smoke.html`: выбор острова, «Берег», «Изнутри», «Вулкан» и кнопки качества. В обычной игре осмотреть пальмы у берега и внутренние пруды, затем проверить подход к каждому причалу. Для горизонта high используется `/scripts/reflection-smoke.html`.

Это улучшение существующей геометрии, не финальная художественная замена всех островных моделей. Пакет новых пропсов, о котором капитан сообщил Claude, сюда ещё не поступал; он остаётся отдельной задачей дорожной карты. События в длинных морских переходах, сжатие ассетов и LOD не добавлены. Телефон, FPS и общая память устройства **не проверены**. Геометрия и несколько карт грунта увеличили нагрузку; instancing уменьшает число вызовов отрисовки, но не число обрабатываемых треугольников.

Нужно независимое ревью текущего HEAD PR #13; старое CHANGES REQUESTED не считать снятым без ответа Claude. При объединении с новым PR #12 понадобится согласовать `src/kit.js`: V6 сохраняет свои UV-карты, островам применяется новый грунт/древесина, остальному киту — прежняя детализация. Такое разрешение проверено только в локальной preview-ветке. `main` не изменялся.
