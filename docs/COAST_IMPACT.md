# Береговые удары и штурвал в бою

Реализовано по решению капитана в комментарии PR #10. Включается в общий PR `codex/gameplay-batch`; слияния с main нет.

- Контакт корпуса игрока с сушей на скорости выше 2 м/с наносит 4–25 единиц урона, зависит от скорости. Повторный урон ограничен паузой 1,2 с; есть звук и сообщение. Медленное касание сохраняет прежнее отделение от берега.
- При потере всей прочности вне боя показывается сообщение о кораблекрушении. Ремонт возвращает корабль в безопасную стартовую воду с убранными парусами, сохраняя золото, острова и состояние босса.
- При начале боя капитан возвращается к штурвалу. Кнопка палубы и F недоступны до окончания боя. Вне боя ходьба под парусами разрешена.
- Бессмертие предотвращает урон, сохраняя звук и физическое отделение. Урон от берега относится только к игроку; баланс босса не менялся.

Проверки: `npm test` 44/44, `npm run build` успешно; встроенный браузер/WebGL, medium: `scripts/safety-smoke.html` 16/16, `scripts/deck-smoke.html` 34/34, `scripts/scale-smoke.html` 39/39. Результаты и снимок в `coast-impact/`. Телефон и FPS на устройстве не проверены. Предупреждение сборки о `fonts/fonts.css` существовало раньше.

Ручная проверка: разогнаться к берегу, сравнить касание малым ходом и на полном ходу; повторить с низкой прочностью и воспользоваться ремонтом. Начать бой из режима палубы, проверить штурвал, F и обе стороны пушек. Технические страницы проверок изменяют только тестовую сессию и не предназначены для сохранения прохождения.
