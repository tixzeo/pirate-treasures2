# Пиратские сокровища 2

Вторая часть «Пиратских сокровищ», теперь в 3D на Three.js. Жанр — гибрид: корабль плавает по открытому морю, с боссами идут морские бои с пушками, а на островах клад добывают в «три в ряд» (логика перенесена из первой части).

## Прототип

- Море на шейдере: волны Герстнера с острыми гребнями, рябь по карте нормалей Артема (`public/textures/sea`), отражение неба по Френелю, просвет гребней против солнца, блики, кружевная пена по текстуре пены (гребни, прибой, бурун у носа и расходящиеся «усы» следа), бирюзовые отмели с песком и бликами на дне.
- Жизнь на воде (Water Life Pack Артема, `public/models/water`, `src/life.js`): буи-ворота на подходе к каждому причалу (корабль их расталкивает), чайки над островами и над кораблём, рыбы выпрыгивают по курсу, бочки и обломки дрейфуют по морю. Когда «Каракатица» тонет, Шрам уплывает на своей шлюпке, вокруг остаются обломки.
- Корабль игрока: W/S — паруса по шагу (задний ход, убраны, малый, половина, полный), A/D — руль, Q/E — залп левым/правым бортом. У корабля инерция: разгон несколько секунд, долгий выбег, руль работает только на ходу. На телефоне — штурвал-джойстик и кнопки.
- Швартовка: у каждого острова причал и контур места на воде. Сойти на берег можно, только встав в контур: ближе 3 м, вдоль причала (до 12°) и медленнее 2,5 узла. Причал сейчас временный, его заменит модель.
- World Kit Артема (`public/models/kit`, `src/kit.js`): бригантина и «Каракатица» с качающимися парусами и флагами, три острова, причалы из сегментов, пальмы и камни, клетки и пять фишек «три в ряд». Пока набор грузится, видны встроенные фигуры.
- Камера: тянуть мышью или пальцем — облёт вокруг корабля, колесо — приближение. На ходу вид сам возвращается за корму через 3 секунды.
- Персонажи (модели Артема, `public/models/characters`, сжаты в WebP + meshopt): капитан и боцман на палубе, Тим появляется после победы, Шрам на «Каракатице», портреты в диалогах.
- Путь: Остров Креста → Бухта Попугая → Остров Черепа → бой с «Каракатицей». Сверху всегда видно следующую цель со стрелкой и расстоянием, над целью горит столб света.
- На островах «три в ряд» 8×8 (уровни 1–3 из первой части): клетки поля, подсветка выбора и соседей, подсказка, светящиеся бомбы.
- «Каракатица» тонет по стадиям (крен, нос вверх, уходит кормой), оставляет обломки и пропадает с карты; Шрам гребёт прочь на шлюпке.
- Прогресс сохраняется в браузере.
- God-меню (кнопка God или клавиша `): сброс прогресса, телепорт, победа на острове, бомбы, бессмертие, ускорение, FPS и копия состояния игры для багрепорта. Выключается флагом `GOD_MENU` в `src/god.js`.

## Текстуры

`public/textures` — PBR-пак «Pirate Treasures» (512×512, бесшовные): basecolor в sRGB, normal/roughness/metallic в линейном пространстве. Материалы собираются в `src/materials.js`.

## Запуск

```
npm install
npm run dev      # локальный сервер
npm test         # тесты логики «три в ряд»
npm run build    # сборка в dist/ с относительными путями, под Яндекс Игры
```
