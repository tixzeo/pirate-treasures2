# Пиратские сокровища 2

Вторая часть «Пиратских сокровищ», теперь в 3D на Three.js. Жанр — гибрид: корабль плавает по открытому морю, с боссами идут морские бои с пушками, а на островах клад добывают в «три в ряд» (логика перенесена из первой части).

## Прототип

- Море на шейдере: волны, блики солнца, пена на гребнях, бирюзовая вода и прибой у островов, пенный след за кораблём, облака.
- Корабль игрока: W/S — паруса, A/D — руль, Q/E — залп левым/правым бортом. На телефоне — штурвал-джойстик и кнопки.
- Путь: Остров Креста → Бухта Попугая → Остров Черепа → бой с «Каракатицей». Сверху всегда видно следующую цель со стрелкой и расстоянием, над целью горит столб света.
- На островах «три в ряд» 8×8 (уровни 1–3 из первой части): клетки поля, подсветка выбора и соседей, подсказка, светящиеся бомбы.
- «Каракатица» тонет по стадиям (крен, нос вверх, уходит кормой), оставляет обломки и пропадает с карты.
- Прогресс сохраняется в браузере.
- God-меню (кнопка God или клавиша `): сброс прогресса, телепорт, победа на острове, бомбы, бессмертие, ускорение, FPS и копия состояния игры для багрепорта. Выключается флагом `GOD_MENU` в `src/god.js`.

## Текстуры

`public/textures` — PBR-пак «Pirate Treasures» (512×512, бесшовные): basecolor в sRGB, normal/roughness/metallic в линейном пространстве. Материалы собираются в `src/materials.js`.

## Запуск

```
npm install
npm run dev      # локальный сервер
npm test         # тесты логики «три в ряд»
npm run build    # сборка в dist/ с относительными путями, под Яндекс Игры
```
