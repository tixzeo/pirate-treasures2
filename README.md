# Пиратские сокровища 2

Вторая часть «Пиратских сокровищ», теперь в 3D на Three.js. Жанр — гибрид: корабль плавает по открытому морю, с боссами идут морские бои с пушками, а на островах клад добывают в «три в ряд» (логика перенесена из первой части).

## Прототип

- Море с волнами, небо, острова.
- Корабль игрока: W/S — паруса, A/D — руль, Q/E — залп левым/правым бортом. На телефоне — джойстик и кнопки.
- Остров Креста: подплывите в золотой круг и сойдите на берег, там поле 8×8 из 3D-сокровищ (20 ходов, 800 очков, как первый остров первой части). Ядра, бочки пороха и компас-бомбы работают как раньше.
- Босс «Каракатица» капитана Шрама патрулирует неподалёку и нападает, если подплыть близко.

## Запуск

```
npm install
npm run dev      # локальный сервер
npm test         # тесты логики «три в ряд»
npm run build    # сборка в dist/ с относительными путями, под Яндекс Игры
```
